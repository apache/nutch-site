The 0.9 release of Nutch is now available. This is the second release of Nutch based entirely on the underlying Hadoop platform. This release includes several critical bug fixes, as well as key speedups described in more detail at [Sami Siren's blog](http://blog.foofactory.fi/2007/03/twice-speed-half-size.html). See [list of changes](https://archive.apache.org/dist/nutch/CHANGES-0.9.txt) made in this version. The release is available [here](http://www.apache.org/dyn/closer.cgi/nutch/).
