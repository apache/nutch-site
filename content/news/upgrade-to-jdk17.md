Nutch v1.22 will be the last version to run on Java 11.

Starting with the development of version 1.23 we will migrate to Java 17.
To run or compile Nutch, a Java 17 runtime (JRE) and JDK will then be required.

See also the [discussion on the Nutch development mailing list](https://lists.apache.org/thread/ogbof5ttk6cf6tzwhh3oqwlnn24spzy9).
